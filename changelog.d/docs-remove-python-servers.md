### Docs: the deprecated Python servers are gone from secantusdb.com/docs

The documentation now describes only the two Rust servers.

#### Removed

- The "Deprecated: Python servers" page and the Python API reference.
- The twenty Python-server validation reports.
- The Python-server column of the feature comparison, and the Python-server
  asides on other pages.

#### Fixed

- The website's driver panels show the Rust server's pass rates, but their
  "Read the report" links opened the Python-server reports. They now open
  the Rust-server reports, as do the links in the docs index and the
  validation summary.
