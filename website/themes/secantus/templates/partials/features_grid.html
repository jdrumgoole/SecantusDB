Geospatial — 2d & 2dsphere

$geoWithin, $geoIntersects, $near, $nearSphere, and $geoNear all accelerated by either index type. S2 cell coverings for GeoJSON; quadtree-decomposed Z-order ranges for legacy [x, y] pairs. Compound geo+scalar indexes work too.

Native TLS & mTLS

[tls] cert_file + key_file wraps accepted sockets in TLS before the wire protocol starts — no reverse proxy required. Add ca_file + require_client_cert for mTLS (transport-layer client-cert verification). SCRAM-SHA-256 still identifies the user on top.
