Performance

A like-for-like benchmark currently has SecantusDB ~8×–46× slower per operation than mongod — the storage engine is the same WiredTiger C library, but the layers above it are Python. CRUD reads sit near the low end; bulk update / delete and aggregation at the high end. The trade is conformance and WiredTiger durability over per-op latency — for ephemeral test and dev data, the wall-clock difference rarely matters. Benchmark & methodology →

Every major MongoDB driver works

SecantusDB is validated against the official driver test suites, unmodified — the same tests the driver maintainers run against a real mongod. Six driver suites — Python, Java, Node.js, Go, Ruby, Rust — plus PHP feature smokes. One wire protocol. pymongo is the deepest suite we run and the only one below 100% — the long tail of edge cases lives there; the others, mongo-java-driver's 4,256 tests included, pass clean and unmodified.
