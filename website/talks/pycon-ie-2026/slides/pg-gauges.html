Rust PostgreSQL server 0.1.0-beta.17 · weekly gauge run, 16 November 2026

The same idea as the MongoDB gauges: real clients' own test suites, unmodified, against the Rust PostgreSQL server. 13,954 tests pass across psycopg, SQLAlchemy, pgx and pgjdbc.

psycopg 99.9%, one failing async concurrency test. SQLAlchemy 100%. pgx, the Go driver, 99.7%. pgjdbc 96.6%: 240 of its 242 failures are one test class, AutoRollbackTest.

sqllogictest: 42 of 60 files pass end to end, with no unexpected failures; the other 18 are files where the corpus expects SQLite's behaviour and PostgreSQL differs too.

pgtest, CockroachDB's wire-protocol tests, is the weak spot: 24 of 57 files pass, 17 fail. That's the clearest list of PostgreSQL behaviour still to build.
