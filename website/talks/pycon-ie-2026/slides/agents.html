Act four · Working with AI agents

One developer, many sessions

What worked

Backlog items, end to end

What it took

Written rules

Agents follow the rules you write down. The rules are the product.

What worked: Claude Code sessions working backlog items end to end: reproduce against mongod or PostgreSQL, fix, run the gate, open a PR, get CI green. Of the 5,115 commits since 26 April, 3,866, about three quarters, carry a Claude co-author line (19 November; recount before the talk).

What it took: written rules in CLAUDE.md and in skills; one server per session; a pushed branch as the claim on an item; a machine-wide build budget. Two sessions once built the same item twice, hence the claim. Eight agents at cargo's default job count pushed the load average to 66 on 12 cores, hence the budget.

Time: ~1½ min
