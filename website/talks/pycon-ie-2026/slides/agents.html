How the way of working changed. It started manually, prompt by prompt. Then it moved to plans: agree a plan, then let Claude Code build it. Then auto mode: Claude runs its tools without asking at every step. Now everything is done as a goal, and a goal can run for days on end.

The bill followed: from the free plan to the Ultra plan over a couple of weeks.

The instructions grew up too. It started as one big CLAUDE.md. That is now broken into skills, each loaded only when the work needs it: releases, the backlog, probing against mongod, the website.

About three quarters of the commits carry a Claude co-author line (3,866 of 5,115 on 19 November).

Time: ~1½ min
