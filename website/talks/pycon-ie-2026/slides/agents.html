Working with AI agents

One developer, many sessions

What worked

Claude Code sessions working backlog items end to end: reproduce against mongod or PostgreSQL, fix, gate, PR, green CI. Most commits are co-authored.

What it took

Written rules in CLAUDE.md and skills, one server per session, a pushed branch as a claim, and a machine-wide build budget.

Agents follow the rules you write down. The rules are the product.

About 3,000 of ~4,700 commits carry a Claude co-author line. Stories: two parallel sessions built the same item twice — hence claim-by-pushed-branch. Eight agents at default cargo jobs pushed load average to 66 on 12 cores — hence the budget. ~3 min.
