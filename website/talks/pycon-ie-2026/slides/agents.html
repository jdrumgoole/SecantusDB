One developer, many sessions.

What worked: Claude Code sessions working backlog items end to end: reproduce against mongod or PostgreSQL, fix, run the gate, open a PR, get CI green. About 3,000 of the ~4,800 commits carry a Claude co-author line.

What it took: written rules in CLAUDE.md and in skills; one server per session; a pushed branch as the claim on an item; and a machine-wide build budget.

Stories: two parallel sessions built the same item twice, hence claim-by-pushed-branch. Eight agents at cargo's default job count pushed the load average to 66 on 12 cores, hence the budget.

The lesson: agents follow the rules you write down. The rules are the product.

Time: ~3 min
