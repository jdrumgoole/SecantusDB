Why Build a MongoDB Clone?

  • The core of MongoDB, WiredTiger, is still GPL licensed
  • Many applications don’t want a separate server
  • Many applications don’t need resilience
  • Many applications don’t need redundancy
  • A fully open source Rust version would be a cool thing to test the viability of Claude Code

MongoDB's server is source-available, but the storage engine at its core, WiredTiger, is still GPL licensed, so a fully open-source server can be built on the same engine.

Plenty of applications don't want a separate server to run, and don't need replica-set resilience or redundancy: one embedded, single-node database is enough.

And it was a good, unforgiving project for testing how far Claude Code can go.
