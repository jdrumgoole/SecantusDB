SecantusDB

Open Source MongoDB compatible database in Rust
(with a little Postgres on the side)

Joe Drumgoole · secantusdb.com

Hi, I'm Joe. This is the story of building a database: seven months, two languages, two wire protocols.

SecantusDB is two Rust servers: one speaks the MongoDB wire protocol, one speaks PostgreSQL's. Both store data in WiredTiger, the storage engine MongoDB itself ships. It started as a Python prototype, which is why this is a PyCon talk.

Timing plan for the 30-minute slot: about 22 minutes of talk and the rest for questions.
