Building SecantusDB

Two Rust database servers, MongoDB and PostgreSQL, on WiredTiger

Joe Drumgoole · secantusdb.com

Hi, I'm Joe. This is the story of building a database: seven months, two languages, two wire protocols.

SecantusDB is two Rust servers: one speaks the MongoDB wire protocol, one speaks PostgreSQL's. Both store data in WiredTiger, the storage engine MongoDB itself ships.

It started as a Python prototype, which is why this is a PyCon talk. Python taught us the protocol and settled the design; Rust ships it.

Timing plan: intro and usage 5 min, the Python era 5, correctness 6, Rust and Postgres 7, process 4, performance 4, wrap-up and questions 3.

Time: ~1 min
