The same picture as slide 6, with the PostgreSQL stream added underneath.

MongoDB: the drivers speak OP_MSG; secantus-wire turns it into commands.

PostgreSQL: psycopg, pgjdbc, pgx and the rest speak the PostgreSQL wire protocol. libpg_query, PostgreSQL's own parser, parses the SQL, and secantus-pgplan lowers it to the filters the core engine evaluates.

Both land in the same secantus-core and the same WiredTiger storage. They are two separate servers, secantusd-mdb and secantusd-pg, sharing one storage format: a table created through SQL reads back as a collection in the MongoDB server. That is a hand-off, not concurrent serving: WiredTiger's file lock lets one server open a directory at a time.
