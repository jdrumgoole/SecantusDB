What is MongoDB?

  • Source Available Document Database
  • JSON Documents as the coin of the realm
  • Unique JSON based query language
  • Replica sets for resilience
  • Sharding for Scalability

A quick grounding for anyone who hasn't used it.

MongoDB's server is source-available under the SSPL rather than open source. It stores JSON-style documents (BSON on the wire and on disk), and you query it with a JSON-based query language rather than SQL.

Replica sets give it resilience and sharding gives it scale. SecantusDB is deliberately single-node, so those last two are out of scope.
