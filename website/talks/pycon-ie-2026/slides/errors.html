No skip to green. No xfail, no deselect, no retry-past. A WT_PANIC under stress is a bug even if a single-threaded test passes; stress is exactly when a database has to hold.

“Flaky” is a bug report. “Only under load” describes a race; it doesn't excuse it.

The backlog is failing tests. Every open item has an ID and a gap test asserting the real server's answer, so it fails while the item is open, and fixing it turns it into a regression test. 192 items were open across the two Rust servers on 19 November; recount the Backlog-ID lines the day before the talk.
