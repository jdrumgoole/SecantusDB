Cultural rules that matter more than any code.

No skip to green. No xfail, no deselect, no retry-past. A WT_PANIC under stress is a bug, even if a single-threaded test passes; stress is exactly when a database has to hold.

"Flaky" is a bug report. "Only under load" and "only in parallel" describe a race; they don't excuse it.

The backlog is failing tests. Every open item has an ID and a gap test that asserts the real server's answer, so it fails while the item is open. Fixing the item turns it into a regression test, so the backlog can't lie. About 230 items are open across the two Rust servers today.
