Then we did it all again for PostgreSQL.

The extended query protocol, prepared statements and portals, text and binary formats; transactions, savepoints, two-phase commit, COPY, LISTEN and NOTIFY; and the catalog tables clients introspect, so psql and SQLAlchemy just work.

The scope is set by what psycopg's own test suite reaches for, not by a feature list.

The rule: always the most faithful PostgreSQL model. When there's a cheap approximation and a faithful port, we take the port, and sequence the work by cost instead of cutting corners. Serializable isolation is ported from PostgreSQL's own predicate.c.

Time: ~3 min
