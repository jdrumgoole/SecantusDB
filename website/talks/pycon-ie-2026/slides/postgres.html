The second protocol

Then we did it again for PostgreSQL

  • Extended query protocol, prepared statements, text and binary formats
  • Transactions, savepoints, two-phase commit, COPY, LISTEN / NOTIFY
  • The catalog tables clients introspect, so psql and SQLAlchemy just work
  • Rule: always the most faithful PostgreSQL model — serializable isolation ported from PostgreSQL’s own predicate.c
Scope is set by what psycopg’s own test suite reaches for, not a feature list. The faithfulness rule: when there’s a cheap approximation and a faithful port, we take the port, and sequence the work by cost rather than cutting corners. ~3 min.
