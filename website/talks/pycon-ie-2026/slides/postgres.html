Then we did it all again for PostgreSQL: the extended query protocol, prepared statements and portals, binary formats; transactions, savepoints, two-phase commit, COPY, LISTEN and NOTIFY; and the catalog tables psql and SQLAlchemy introspect.

The scope is set by what psycopg's own test suite reaches for. On 13 October, of the 5,731 psycopg tests that ran, 5,544 passed and none failed; the rest psycopg itself skips or expects to fail.

The rule: always the most faithful PostgreSQL model. Serializable isolation is ported from PostgreSQL's own predicate.c.
