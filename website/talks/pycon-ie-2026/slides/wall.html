Why Rust: native speed, real threads, one self-contained binary.

An honest PyCon moment: this is a Python talk where Python got replaced.

What Python gave us: we learned the protocol fast, and designed the storage layout, the index planner, the oplog and change streams in it first.

What it couldn't do: latency and concurrency. A benchmark showing the Python server slow was reporting the design, not a bug.

What it still does: pytest is the test runner for both Rust servers, pymongo and psycopg are the clients we measure against, and pip install is how most people will get the binaries.

In October 2026 the Python servers were deprecated; every new feature goes to Rust.
