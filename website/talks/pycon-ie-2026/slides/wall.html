Act three · Hitting the wall

Python proved the design. Rust ships it.

What Python gave us

The protocol learned fast, the storage layout, the index planner, the oplog and change streams — all designed first in Python.

What it couldn’t

Latency and concurrency. A benchmark showing the Python server slow was reporting the design, not a bug.

October 2026: the Python servers are deprecated. Every new feature goes to Rust.

Honest PyCon moment: this is a Python talk where Python got replaced. But Python was the prototype that made the Rust version possible, and Python is still the test runner — pytest drives the Rust servers. ~2 min.
