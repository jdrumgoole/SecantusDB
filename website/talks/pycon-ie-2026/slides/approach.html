How to Approach The Problem

  1. Claude all the Way
  2. Vendored in WiredTiger
  3. Vendored in Driver Test Suites
  4. First build in Python for correctness
  5. Then build in Rust for performance
  6. Make the Rust version canonical

Python first, for correctness. The first commit, on 26 April 2026, was a MongoDB wire server in Python. Python was the fastest way to learn the protocol, and pymongo is the client we measure against. The scope came from one question: what does pymongo actually send?

Then Rust, for performance. Same design, same storage engine, rewritten for latency and concurrency.

Then Rust only. In October 2026 the Rust server became canonical and the Python servers were deprecated.

Time: ~1½ min
