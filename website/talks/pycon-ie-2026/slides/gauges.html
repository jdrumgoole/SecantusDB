A hang is a failure, never a skip.

Driver authors have already written thousands of tests describing what a server must do. We run the official MongoDB drivers' own test suites, thirteen of them across eleven languages, each a git submodule with zero edits, run weekly against the Rust server.

A hang is a failure, never a skip. The Go gauge reported 100% for months, because a hung test killed the run at 476 of 481 tests before the failures were counted. Now we count tests started against tests that reported.
