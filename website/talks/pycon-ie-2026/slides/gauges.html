Borrow other people's test suites, unmodified.

Driver authors have already written thousands of tests describing what a server must do. We run thirteen MongoDB driver suites (pymongo sync and async, Go, Node, Java, Kotlin, Ruby, Rust, both PHP drivers, C, C++ and C#) and seven SQL suites, including psycopg, sqllogictest and SQLAlchemy's dialect tests.

Each one is a git submodule, pointed at our server, with zero edits. They run weekly against both Rust servers.

The rule: a hang or a timeout is a failure, never a skip. Anecdote: the Go gauge reported 100% for months, because a hung test killed the run at 476 of 481 tests before the failures were counted. So now we count tests started against tests that reported.
