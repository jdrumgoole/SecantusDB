WiredTiger

The drivers exist: every official MongoDB driver speaks the same wire protocol. These are the eleven languages whose official drivers' own test suites we run unmodified: pymongo, Node.js, Java, Kotlin, Go, Rust, C, C++, C#, Ruby and PHP. Their authors have already written thousands of tests describing what a server must do.

The engine exists: WiredTiger gives us checkpoints, transactions and durability. The gap is the server in between, and all the hard work is in being faithful.

Walk the stack: OP_MSG arrives over TCP; secantus-wire turns it into commands; secantus-core runs the query, update and aggregation engines; secantus-storage talks to WiredTiger.

Time: ~2½ min
