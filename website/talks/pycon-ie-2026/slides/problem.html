Why build a database?

Two protocols everyone already speaks

The clients exist

Drivers in a dozen languages

The engine exists

WiredTiger, inside MongoDB

The gap

One small server for both

The motivation: we didn't have to invent a client ecosystem or a storage engine.

The clients exist. pymongo, psycopg, SQLAlchemy and official drivers in a dozen languages. If you speak their wire protocol correctly, they all just work, and their authors have already written thousands of tests describing what a server must do.

The engine exists. WiredTiger gives us checkpoints, transactions and durability. We don't write B-trees or a write-ahead log.

The gap is the server in between: one small, self-contained server that is faithful to the real products, starts in one line and needs nothing else installed. All the hard work is in being faithful.

Time: ~2 min
