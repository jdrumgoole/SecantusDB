The clients exist: pymongo, psycopg, SQLAlchemy, drivers in a dozen languages, and their authors have already written thousands of tests describing what a server must do. The engine exists: WiredTiger gives us checkpoints, transactions and durability. The gap is the server in between, and all the hard work is in being faithful.

MongoDB row: OP_MSG in, secantus-wire turns it into commands, secantus-core runs the query, update and aggregation engines, secantus-storage talks to WiredTiger.

PostgreSQL row: libpg_query is PostgreSQL's own parser; secantus-pgplan lowers the SQL to the filters the same core engine evaluates, in the same tables and files.

A CREATE TABLE in the Postgres server reads back as a collection in the MongoDB server, as a hand-off: WiredTiger's file lock lets only one server open a directory at a time.
