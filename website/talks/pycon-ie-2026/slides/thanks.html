Take questions. The links are on the previous slide; step back to it if someone asks where to find something.

Likely questions:

  • Why not FerretDB? FerretDB translates MongoDB commands onto PostgreSQL. SecantusDB stores BSON in WiredTiger, the engine mongod ships, and measures itself against mongod 8.x.
  • Can both servers serve one directory at once? No. WiredTiger's file lock allows one server at a time; SQL to MongoDB works as a hand-off; MongoDB to SQL does not, because the PostgreSQL server only sees tables its own CREATE TABLE made.
  • Joins, and SQL that isn't a filter? Joins work. What the server doesn't support is refused by name (SQLSTATE 0A000) and filed as a backlog item, never approximated.
  • Benchmark version? Latency ran against mongod 8.0.38; conformance is measured against 8.2.
  • Licence? GPLv2.
  • Windows? The MongoDB server has a Windows build; the PostgreSQL server is Linux and macOS.
