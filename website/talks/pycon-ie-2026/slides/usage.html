Start a database in one line — or run it as a server

# embedded, from Python
from secantusdb import MongoServer
import pymongo

with MongoServer() as server:
    client = pymongo.MongoClient(server.uri)
    db = client.mydb
    db.users.insert_one({"name": "Ada"})
# standalone, like mongod
$ secantusd-mdb &

Show this early so the room knows what we're talking about.

Left: embedded. After the pip install, MongoServer() starts the MongoDB server on a free port and hands you a URI. Any pymongo code works against it unchanged.

Right: the same binary runs standalone, wherever you'd run mongod, and mongosh connects with no flags or plugins. mongosh's own banner says it is talking to MongoDB 8.2.11, and its prompt reads secantus [direct: primary]: the single-node replica set the server advertises. (A real session, captured 20 November 2026.)
