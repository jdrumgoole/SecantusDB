What it looks like

Start a database in one line — or run it as a server

# embedded, from Python
from secantusdb import MongoServer
import pymongo

with MongoServer() as server:
    db = pymongo.MongoClient(server.uri).app
    db.users.insert_one({"name": "Ada"})
# standalone, like mongod / postgres
$ secantusd-mdb --port 27017 \
    --storage-path ./data

$ secantusd-pg ./pg-data 127.0.0.1:5433

$ mongosh mongodb://127.0.0.1:27017
$ psql -h 127.0.0.1 -p 5433

Show this early so the room knows what we're talking about.

Left: embedded, through the PyPI launcher. pip install SecantusDB gives you both Rust servers plus the secantusdb package; MongoServer() starts one on a free port and gives you a URI. Any pymongo code works against it unchanged.

Right: the same binaries run standalone, as a daemon, exactly where you'd run mongod or postgres. secantusd-pg takes the storage path and the bind address as arguments.

Point out that mongosh and psql connect to them with no flags or plugins: these are the real clients, talking to our servers.

Time: ~2 min
