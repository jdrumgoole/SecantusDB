What it looks like

Start a database in one line — or run it as a server

# embedded, from Python
from secantusdb import MongoServer
import pymongo

with MongoServer() as server:
    db = pymongo.MongoClient(server.uri).app
    db.users.insert_one({"name": "Ada"})
# standalone, like mongod / postgres
$ secantusd-mdb --port 27017 \
    --storage-path ./data

$ secantusd-pg ./pg-data 127.0.0.1:5433

$ mongosh mongodb://127.0.0.1:27017
$ psql -h 127.0.0.1 -p 5433

Two Rust binaries, secantusd-mdb and secantusd-pg. Any MongoDB or PostgreSQL driver connects unchanged.

Show this early so the room knows what we are talking about. Left: embedded through the PyPI launcher. Right: the same servers run standalone, as a daemon, exactly where you’d run mongod or postgres. secantusd-pg takes the storage path and bind address as arguments. ~2 min.
