The general skills

start-session

Opens a session: checks the repo and machine are current, refreshes the code graph, clears leftovers

close-session

Lands outstanding work, records what is left, tears down branches and worktrees

secantusdb-release

Releases both Rust servers: tags, binaries, the PyPI wheel, through to the live site

secantusdb-website

The secantusdb.com site: edit on a branch, PR, deploy, a blog post per release

conformance-gauges

Runs the 13 MongoDB driver test suites, unmodified, against the server

ci-check

Checks CI after every push; a failure is a bug, with a catalogue of known patterns

Sixteen skills now hold what used to be one big CLAUDE.md. These six are the general ones: how a session starts and ends, how a release and the website go out, how the driver gauges run, and how CI is checked after every push.

The other ten are about the code itself: the backlog protocol, probing against mongod, building and testing, measuring, the explain and planner internals, the PostgreSQL server, and fixing one backlog item end to end.

Time: ~1 min
