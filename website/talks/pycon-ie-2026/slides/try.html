Try it

Three ways to install

PyPI

pip install SecantusDB

Both Rust servers plus the secantusdb launcher. Linux x86_64, macOS arm64.

crates.io

cargo install secantus-mdb --version 0.5.3-beta.197
cargo install secantus-pg  --version 0.1.0-beta.19

Builds from source, WiredTiger included. Or embed as a Rust library.

GitHub Releases: prebuilt binaries

# macOS arm64 shown; on Linux use x86_64-unknown-linux-gnu
R=https://github.com/jdrumgoole/SecantusDB/releases/download
curl -LO $R/secantusdb-v0.5.3-beta.197/secantusdb-0.5.3-beta.197-aarch64-apple-darwin.tar.gz
tar xzf secantusdb-0.5.3-beta.197-aarch64-apple-darwin.tar.gz
./secantusdb-0.5.3-beta.197-aarch64-apple-darwin/secantusd-mdb --port 27017

secantusd-pg: the same steps from the secantusd-pg-v0.1.0-beta.19 release. Each archive has a .sha256 beside it. No Python, no toolchain.

Nothing compiles on pip install. cargo install needs a C toolchain and CMake because it builds WiredTiger. Both crates are pre-releases, so cargo needs the exact --version. The binary commands were run verbatim on macOS arm64 on 17 November 2026; check for newer releases before the talk. Windows (mdb only) is a .tar.gz on the same release. ~2 min.
