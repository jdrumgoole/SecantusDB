Try it

Three ways to install

PyPI

pip install SecantusDB

Linux x86_64, macOS arm64

crates.io

cargo install secantus-mdb --version 0.5.3-beta.198
cargo install secantus-pg  --version 0.1.0-beta.20

Builds from source

GitHub Releases: prebuilt binaries

# macOS arm64 shown; on Linux use x86_64-unknown-linux-gnu
R=https://github.com/jdrumgoole/SecantusDB/releases/download
curl -LO $R/secantusdb-v0.5.3-beta.198/secantusdb-0.5.3-beta.198-aarch64-apple-darwin.tar.gz
tar xzf secantusdb-0.5.3-beta.198-aarch64-apple-darwin.tar.gz
./secantusdb-0.5.3-beta.198-aarch64-apple-darwin/secantusd-mdb --port 27017

secantusd-pg: same steps, its own release

Three ways to install.

PyPI: nothing compiles on pip install; the wheel carries prebuilt binaries for Linux x86_64 and macOS arm64.

crates.io: cargo install needs a C toolchain and CMake, because it builds WiredTiger. Both crates are pre-releases, so cargo needs the exact --version.

GitHub Releases: the binary commands were run verbatim on macOS arm64 on 17 November 2026. Check for newer releases before the talk. Windows (MongoDB server only) is a .tar.gz on the same release.

Time: ~2 min
