One line to install

pip install SecantusDB

crates.io

cargo install secantus-mdb --version 0.5.3-beta.198

GitHub Releases

Standalone secantusd-mdb binaries for Linux, macOS and Windows

Say the pip line and move on; the rest is for the photo.

PyPI: nothing compiles on pip install; the wheel carries the prebuilt server, for Linux x86_64 and macOS arm64. crates.io: cargo install builds WiredTiger, so it needs a C toolchain and CMake, and the crate is a pre-release, so cargo needs the exact --version. GitHub Releases: download, untar, run.

Check for a newer release the day before and update the version here.

Time: ~1 min
