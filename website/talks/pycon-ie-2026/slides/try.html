Try it

Three ways to install

PyPI

pip install SecantusDB

Both Rust servers plus the secantusdb launcher. Linux x86_64, macOS arm64.

crates.io

cargo install secantus-mdb \
  --version 0.5.3-beta.197
cargo install secantus-pg \
  --version 0.1.0-beta.19

Builds from source, WiredTiger included. Or embed as a Rust library.

Binaries

secantusd-mdb
secantusd-pg

Prebuilt on GitHub Releases. Run standalone, like mongod or postgres.

Recap the usage slide. Nothing compiles on pip install. cargo install needs a C toolchain and CMake because it builds WiredTiger. Both crates are pre-releases, so cargo needs the exact --version; check for newer versions before the talk. Demo here if time allows. ~2 min.
