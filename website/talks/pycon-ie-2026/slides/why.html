Why

Why build MongoDB in Rust?

  1. Test AI coding tools on real work
  2. An open-source MongoDB
  3. Embeddable, like SQLite

Three reasons, and I'll be honest about all of them.

AI coding tools. I wanted to know what Claude Code can really do on a large, correctness-critical codebase, not a toy app. A database is about as unforgiving a test as you can pick.

An open-source MongoDB. The MongoDB wire protocol is everywhere, but the server isn't open source in the usual sense. A server that speaks the protocol faithfully is useful on its own.

Embeddable, like SQLite. One self-contained binary you can start from a program, a script or a test in one line, with nothing else to install.

Time: ~1 min
