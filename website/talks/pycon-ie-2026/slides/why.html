Why

Why build a database?

  1. Test AI coding tools on real work
  2. An Open Source MongoDB compatible database
  3. Embeddable, like SQLite

Three reasons, and I'll be honest about all of them.

AI coding tools. I wanted to know what Claude Code can really do on a large, correctness-critical codebase. A database is about as unforgiving a test as you can pick.

Open Source MongoDB compatible. The MongoDB wire protocol is everywhere, but MongoDB's own server is under the SSPL, which isn't an OSI-approved licence. SecantusDB is GPLv2.

Embeddable, like SQLite. One self-contained binary you can start from a program, a script or a test in one line.

Rust comes later in the story: it started in Python.
